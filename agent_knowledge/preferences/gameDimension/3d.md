DIMENSION = 3D.

- Use `THREE.PerspectiveCamera`. Default `fov = 50`, `near = 0.1`, `far = 200`.
- Default camera setup: isometric-ish (Crossy-Road style) — position roughly `(7, 9, 12)` relative to the player, look at the player. Smooth follow with `camera.position.lerp(targetPos, 0.1)` per frame.
- For first-person / third-person follow games, use a dedicated camera rig: a `THREE.Object3D` holds the camera and is parented to the player or to a spring-arm.
- Renderer: `antialias: true` only if devicePixelRatio < 2 (otherwise too expensive on phones). Always `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`.
- Shadows: `renderer.shadowMap.enabled = true; renderer.shadowMap.type = THREE.PCFSoftShadowMap;`. Single shadow-casting `THREE.DirectionalLight`. Shadow map size `1024×1024` MAX. Position the shadow camera frustum tight to the player so shadows stay sharp:
  ```js
  light.shadow.camera.left = -10;
  light.shadow.camera.right = 10;
  light.shadow.camera.top = 10;
  light.shadow.camera.bottom = -10;
  light.shadow.camera.near = 1;
  light.shadow.camera.far = 50;
  ```
  Move the light + its target with the player every frame to keep shadows in view.
- Add `THREE.HemisphereLight` (sky `#bde7ff`, ground `#3a4a6a`, intensity `0.6`) for ambient grounding.
- Avoid `MeshStandardMaterial` unless the art style needs PBR. Prefer `MeshLambertMaterial` (cheap, supports lights + shadows) or `MeshBasicMaterial` (no lighting).
- Fog (`THREE.Fog`) is encouraged to hide pop-in on procedurally generated worlds.
