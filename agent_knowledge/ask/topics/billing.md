# Credits, tiers, cashback

## Credits

- The platform uses **credits**.
- Conversion: **50 credits = $1 USD**.
- Owners top up via Telegram Stars (and partner channels). Balance is
  visible in the chat header at all times.

## What costs credits

- **Plan** — small, varies by tier; pre-charged when the owner taps Plan.
- **Build** — pre-charged when the owner taps Build. Cost shown on the
  button.
- **Update** — pre-charged when the owner sends an update request and
  approves the spend.
- **Ask** — answering owner questions in chat (this assistant). Always
  small.

## Cashback

If a build or update finishes cheaper than the pre-charge, the platform
returns the difference to the owner's balance automatically. They don't
have to claim anything.

## Performance tiers

- **Tier 1** is the default: balanced cost vs quality.
- Higher tiers swap in stronger underlying models for plan / build / update
  steps. Useful for complex apps, games with intricate logic, or whenever
  the previous tier produced something the owner wasn't happy with.
- Each tier has its own pricing for plan / build / update. The owner picks
  the tier per project.

## Free vs paid features

- The build itself is paid (credits).
- Stars payments and TON payments are extra one-time **feature unlocks**
  on top — independent of credits, purchased per project.
